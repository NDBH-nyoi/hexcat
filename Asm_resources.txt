55 48 89 e5
Where
55 -> 50(push) + (r=5) rbp
48 -> REX.W ; A prefix modifier
89 -> Move instruction (r=5) so dest is rbp, e5 as an actual seperate argument()

So ModR/M (Mode-Register-Memory) defines r.
So if the instruction has an "r" op field, that means the entire byte after gets intepreted as modR/M.
